איך לקבל GitHub Copilot חינמי?

GitHub מציעה את Copilot בחינם לסטודנטים באמצעות תוכנית החינוך שלה. הנה איך תוכלו לקבל את ההטבה:

  1. היכנסו לאתר GitHub Education דרך הקישור הבא: GitHub Education Pack.
  2. לחצו על "Get your pack" והירשמו עם המייל של האוניברסיטה username@telem.openu.ac.il.
  3. במקום "username" כתבו את היוזר איתו אתם מתחברים לאתר של האוניברסיטה.
  4. לאחר זמן קצר תקבלו אישור למייל שלכם (איתו אתם רשומים באתר האוניברסיטה).
  5. לאחר קבלת האישור, התחברו ל-GitHub והפעילו את Copilot דרך ההגדרות.
